Java 全栈 12 周逐日计划

配套阅读

路线总纲见 你好（阶段划分、项目阶梯、资源清单、方法论）。

你的起点与节奏

  • 起点：零基础，但做过小项目 → 有直觉、缺体系 → 第 1–2 周可压缩（见文末「弹性调整」）
  • 投入：每天 6 小时 × 每周 6 天 = 36 小时/周，12 周 ≈ 430 小时
  • 强度说明：这是「脱产级」强度，足够从零走到能独立交付一个上线项目的初级/中级水平

每日 6 小时时间块模板

时段 时长 内容 要求
块 1 2.0 h 理论学习（文档/视频） 只学当天任务，不贪多
块 2 3.0 h 动手写代码 不写代码的学习不算学习
块 3 0.5 h LeetCode 算法 每天 1–2 题，写复杂度分析
块 4 0.5 h 笔记 + Git 提交 每天必须有一次 commit
三条铁律

  1. 不出三天不换教程：选一套就跟到底，禁绝"教程收集癖"
  2. 当天代码当天提交：GitHub 绿格子是你最好的进度条
  3. 卡住超过 1 小时就记录并绕过：写进「卡点清单」，周末集中解决

进度打卡表

第 1 周 ｜ Java 基础语法与环境（阶段 0）

周目标：搭好全部工具链，掌握 Java 语法主干，建立每日节奏。
算法主题：数组、字符串、哈希表

Day 任务
D1 安装 JDK 17/21 + IntelliJ IDEA + Git + Maven；配置环境变量；跑通 Hello World；注册 GitHub，把代码推上去
D2 变量与数据类型、运算符、流程控制（if/switch/for/while/break/continue）；练习：九九乘法表、猜数字游戏、手写冒泡排序
D3 数组（一维/二维）、方法定义与重载、可变参数、递归；练习：数组去重、二分查找、斐波那契
D4 String / StringBuilder / String.format；练习：字符串统计、回文判断、大小写与去空格处理
D5 面向对象入门：类与对象、构造器、封装、this、static、包与访问修饰符
D6 继承、多态、抽象类、接口、Object 的 equals/hashCode/toString；练习：写一个「学生管理系统」控制台版
D7 复盘：整理笔记、LeetCode 2 题、把「学生管理系统」重构一遍

验收：能在 IDEA 里独立新建项目并推到 GitHub；能说清重载与重写的区别。

第 2 周 ｜ 集合 · 异常 · 泛型 · IO（阶段 0）

周目标：吃透集合框架与异常处理，这是面试第一高频区。
算法主题：双指针、哈希计数

Day 任务
D1 Collection 体系概览；ArrayList vs LinkedList（底层数组、扩容 1.5 倍、随机访问与增删的复杂度）
D2 HashSet / TreeSet；HashMap 底层（数组+链表+红黑树、hash 扰动、扩容、为何线程不安全）
D3 异常体系（Error/Exception、受检与非受检）、try-catch-finally、自定义异常、try-with-resources
D4 泛型（泛型类/方法、通配符、类型擦除）、包装类与自动装箱、枚举、java.time 日期 API
D5 IO 流：字节流/字符流、缓冲流、转换流、序列化；File 操作；NIO 简介
D6 综合练习：读取日志文件 → 词频统计 → 输出格式化报表（这是 P0 的雏形）
D7 复盘：手写 HashMap 简易版（put/get/扩容）；LeetCode 2 题

验收：能画出 HashMap 结构图并解释扩容过程；能独立写出词频统计程序。

第 3 周 ｜ Lambda + Stream + Maven + P0 项目（阶段 0 收官）

周目标：掌握现代 Java 写法与工程化工具，产出第一个可展示项目。
算法主题：排序、递归、简单动态规划

Day 任务
D1 Lambda 表达式、函数式接口（Function/Consumer/Supplier/Predicate）、方法引用
D2 Stream API：filter / map / sorted / reduce / collect / groupingBy，手写 10 个实战案例
D3 Maven：坐标、依赖作用域与传递、生命周期、插件；多模块工程结构简介
D4 JUnit 5 单元测试入门（@Test、断言、@BeforeEach）；日志 SLF4J + Logback 配置
D5 P0 项目开发：需求拆解 → 设计接口 → JSON 数据读取与解析（Jackson）+ 数据模型定义
D6 P0 项目开发：统计逻辑（分组、排序、Top N）+ 命令行参数 + 报表输出（控制台/Markdown）
D7 P0 项目收尾：异常处理、单元测试、README、Git 提交；对照阶段 0 检查清单

验收（P0 交付物）：Maven 构建通过、有测试、有 README、GitHub 仓库可运行。
里程碑 🏁：阶段 0 完成。

第 4 周 ｜ JVM + 并发入门（阶段 1）

周目标：建立 JVM 与并发的底层认知，这是区分「会写」与「懂」的分水岭。
算法主题：链表、栈与队列

Day 任务
D1 JVM 内存结构：堆、虚拟机栈、本地方法栈、程序计数器、方法区/元空间；对象创建全过程
D2 垃圾回收：引用计数 vs 可达性分析、四种引用、GC 算法（标记清除/复制/标记整理）、分代模型
D3 常见垃圾收集器（Serial / Parallel / CMS / G1 / ZGC 概念）、常见 JVM 参数、jps/jstat/jmap/jstack 实操
D4 类加载机制：加载-验证-准备-解析-初始化、双亲委派、打破双亲委派的场景
D5 线程基础：Thread / Runnable / Callable、线程生命周期、sleep / join / interrupt / setDaemon
D6 线程安全：JMM、可见性与有序性、synchronized 原理（对象头/锁升级）、volatile 语义
D7 复盘：画一张 JVM 内存结构图 + 写一篇笔记；LeetCode 2 题

验收：能解释 i++ 在多线程下为何不安全；能说出 volatile 解决了什么、没解决什么。

第 5 周 ｜ 并发进阶 + P1 项目（阶段 1 收官）

周目标：真正会用并发，手写出线程池。
算法主题：二叉树遍历、递归

Day 任务
D1 CAS 与原子类（AtomicInteger 原理、ABA 问题）、Unsafe 简介
D2 AQS 原理、ReentrantLock、ReadWriteLock、Condition；synchronized 与 Lock 对比
D3 线程池原理：ThreadPoolExecutor 七大参数、任务提交与执行流程、四种拒绝策略、Executors 的坑
D4 阻塞队列（ArrayBlockingQueue / LinkedBlockingQueue）、ConcurrentHashMap 原理
D5 P1 开发：手写简易线程池（核心/最大线程数、队列、拒绝策略）并与 JDK 线程池压测对比
D6 并发工具类（CountDownLatch / CyclicBarrier / Semaphore）、CompletableFuture 异步编排；完成 P1
D7 复盘：阶段 1 检查清单；LeetCode 2 题

验收（P1 交付物）：线程池代码 + 一篇《线程池原理与手写实现》笔记 + 压测数据。
里程碑 🏁：阶段 1 完成。

第 6 周 ｜ MySQL + 网络基础（阶段 2 前置）

周目标：数据库和网络是后端的底座，必须打牢。
算法主题：双指针、滑动窗口

Day 任务
D1 MySQL 安装与连接、建库建表、CRUD、数据类型选择、字符集与排序规则
D2 复杂查询：多表 join、group by / having、子查询、union；索引原理（B+ 树）、联合索引与最左前缀
D3 事务：ACID、四种隔离级别与脏读/不可重复读/幻读、MVCC、行锁表锁；Explain 分析慢 SQL
D4 JDBC 全流程手写一遍（Connection/PreparedStatement/ResultSet）、SQL 注入与预编译、连接池 HikariCP
D5 网络基础：TCP/IP 分层、三次握手四次挥手、HTTP 请求响应报文、常见状态码、Cookie/Session
D6 实战：用 JDBC 把 P0 的数据落库，写查询与聚合统计（为后端项目打基础）
D7 复盘：写《MySQL 索引与事务》笔记；LeetCode 2 题

验收：能给任意一条 SQL 说出它走没走索引、为什么。

第 7 周 ｜ Spring Boot 入门（阶段 2）

周目标：理解 Spring 的核心思想，能独立搭建并跑通一个 Web 服务。

Day 任务
D1 Spring 核心：IoC/DI 思想、Bean 的定义与注入方式、作用域、生命周期
D2 AOP：切面、通知、切点表达式、动态代理（JDK vs CGLIB）；实战：统一日志切面
D3 Spring Boot 3 项目搭建（start.spring.io）、自动配置原理、jar 启动、yml 配置与多环境 Profile
D4 分层架构：Controller / Service / Mapper 各层职责；DTO、VO、Entity 的区分
D5 编写第一个 REST 接口：@RestController、@GetMapping/@PostMapping、参数绑定（@RequestParam/@PathVariable/@RequestBody）
D6 统一响应体封装、全局异常处理（@RestControllerAdvice）、跨域配置、拦截器与过滤器
D7 复盘：写《Spring IoC 与 AOP 到底解决了什么》笔记

验收：能自己讲清"一个请求进来，Spring 是如何找到并调用你的方法的"。

第 8 周 ｜ 持久层 + API 规范（阶段 2）

周目标：把「采集管理平台」的数据层与接口层做出来。

Day 任务
D1 MyBatis-Plus 集成：CRUD、条件构造器 QueryWrapper、常用注解
D2 分页插件、逻辑删除、字段自动填充、乐观锁 @Version
D3 表设计实战：为「GitHub 数据采集管理平台」设计表（用户、采集任务、仓库数据、标签、操作日志），写建表 SQL
D4 参数校验（@Valid + 自定义校验）、全局参数异常处理、Swagger / OpenAPI（springdoc）接口文档
D5 多表关联查询、自定义 XML/注解 SQL、DTO↔VO 转换（BeanUtils/MapStruct）
D6 完成三类接口：用户管理、采集任务管理、数据查询与统计聚合
D7 复盘：用 AI 或自己 review 一遍代码，重构坏味道

验收：接口文档可访问且能直接在 Swagger 上调试通过。

第 9 周 ｜ Redis + 鉴权 + P2 收官（阶段 2）

周目标：补齐缓存与安全，交付完整的后端服务。

Day 任务
D1 Redis 数据结构与常用命令（String/Hash/List/Set/ZSet）、Spring Data Redis 集成、序列化配置
D2 缓存实战（@Cacheable）、缓存穿透/击穿/雪崩的产生与解决方案、缓存与数据库一致性
D3 JWT 鉴权全流程：登录 → 签发 token → 拦截器校验 → 刷新；RBAC 权限模型设计；BCrypt 密码加密
D4 Spring 事务：传播行为、隔离级别、失效场景（自调用、非 public、异常被吞）；Redis 分布式锁实现与踩坑
D5 单元测试（Mockito）+ 集成测试（MockMvc）；接口自测与边界用例
D6 P2 收尾：接口文档、README、Postman 集合、本地全流程演示、Git 提交
D7 复盘：阶段 2 检查清单

验收（P2 交付物）：可运行的完整后端服务（鉴权 + 缓存 + 文档 + 测试）。
里程碑 🏁：阶段 2 完成 —— 此时你已经是「能做后端」的人。

第 10 周 ｜ 前端基础（阶段 3）

周目标：打通前端基础，能看懂并写出页面。

Day 任务
D1 HTML5 常用标签与语义化、表单元素、meta 与 SEO 基础
D2 CSS：选择器与优先级、盒模型、CSS3 变量；Flex 布局专项练习
D3 CSS Grid、定位、过渡动画、响应式（媒体查询）；手写一个静态个人主页
D4 JavaScript 基础：变量与作用域、函数、对象、数组常用方法（map/filter/reduce）、DOM 操作与事件
D5 JS 进阶：ES6+（解构、模板字符串、扩展运算符）、Promise 与 async/await、fetch/axios、模块化 import/export
D6 TypeScript：基础类型、interface/type、泛型、联合类型、枚举；把我们前端的工具函数改成 TS
D7 复盘：写《JS 事件循环与 Promise》笔记；LeetCode 2 题

验收：能独立用 HTML+CSS+JS 写一个带交互的表单页面。

第 11 周 ｜ Vue 3 进阶 + 前后端联调 → P3（阶段 3）

周目标：用 Vue 3 把后端 API 做成交互式系统。

Day 任务
D1 Vue 3 基础：模板语法、指令（v-if/v-for/v-model）、响应式（ref/reactive）、计算属性与侦听器
D2 组件化：组件通信（props / emit / provide-inject）、插槽、生命周期
D3 Vue Router（路由配置、动态路由、路由守卫做登录拦截）、Pinia 状态管理
D4 Element Plus UI 库；Axios 二次封装（统一 baseURL、请求/响应拦截器、自动注入 token、错误提示）
D5 页面开发①：登录页 + 主布局（侧边栏/顶栏）+ 权限路由
D6 页面开发②：数据看板（ECharts 折线/柱状/饼图对接统计接口）+ 列表页/详情页/表单增删改查
D7 P3 收尾：前后端联调、处理跨域、npm run build 打包、更新 README

验收（P3 交付物）：前后端分离的完整可视化系统，本地端到端跑通。
里程碑 🏁：阶段 3 完成 —— 你已经是「全栈」了。

第 12 周 ｜ 容器化 + 部署上线 → P4（阶段 4）

周目标：把项目真正搬到公网，形成可写进简历的交付能力。

Day 任务
D1 云服务器购买与基础操作（SSH、用户与权限、常用命令、防火墙与安全组）、安装 JDK 与 Nginx
D2 Docker 基础：镜像与容器、常用命令、Dockerfile 编写（多阶段构建减小体积）
D3 docker-compose 编排：MySQL + Redis + 后端 + 前端一键启动，数据卷持久化
D4 Nginx：反向代理后端接口、托管前端静态资源、gzip 压缩、HTTPS 证书配置
D5 GitHub Actions CI/CD：push 触发 → 构建 → 测试 → 构建镜像 → 部署到服务器（复用你论文的技术栈）
D6 JMeter 压测接口、定位慢 SQL 与瓶颈、优化后对比数据；上线验收
D7 P4 收尾：写《从零到上线：部署踩坑全记录》；12 周总结复盘

验收（P4 交付物）：域名 + HTTPS 可访问的线上系统 + 一条自动部署流水线。
里程碑 🏁：阶段 4 完成 —— 你具备了「独立交付」的完整闭环。

弹性调整规则

关于「零基础但做过小项目」

第 1–2 周的部分内容你可能有直觉。建议先做一次自测：能否答出「HashMap 为什么线程不安全」「重载和重写的区别」。若两题都流畅，第 1–2 周可压缩到 5–6 天，把省下的时间投到 P0 项目或直接提前进入第 3 周。

进度落后怎么办

  1. 不要补债：落后就按原计划往前，把没完成的项挪进周日的机动时间
  2. 优先级排序：项目产出 > 框架使用 > 底层原理 > 算法刷题
  3. 进度低于 60% 就降级：把 12 周拉长到 14–16 周，别硬撑导致放弃

学不动了怎么办

  • 换「产出」而不是换「课程」：去写代码、去 commit
  • 每个周末必须有一次「跑起来」的成就感（哪怕是修一个 bug）
  • 允许每周有 1 天完全不碰代码
