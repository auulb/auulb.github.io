## Repository Structure存储库结构

This repository holds the content behind the roadmaps on [roadmap.sh](https://roadmap.sh/).  
该存储库包含 [roadmap.sh](https://roadmap.sh/) 上的路线图背后的内容。

```
roadmaps/<roadmap-slug>/content/<topic-slug>@<node-id>.md
```

Each markdown file is the content of a single topic on a roadmap. The node id in the file name is what links it to the topic, so please keep file names intact. Merged changes are synced to the website automatically.  
每个 Markdown 文件都代表路线图上的一个主题的内容。文件名中的节点 ID 用于将其链接到相应的主题，因此请保持文件名不变。合并后的更改会自动同步到网站。

```
git clone git@github.com:nilbuild/developer-roadmap.git --depth 1
cd developer-roadmap
```

`scripts/` holds the sync tooling used by the maintainers, see [scripts/readme.md](https://github.com/nilbuild/developer-roadmap/blob/master/scripts/readme.md) for details.  
`scripts/` 目录下存放着维护人员使用的同步工具，请参阅 详情请参阅 [scripts/readme.md](https://github.com/nilbuild/developer-roadmap/blob/master/scripts/readme.md) 。
